# Semana Acadêmica de Tecnologia

Landing page acadêmica baseada nos frames desktop e mobile do [Figma Design](https://www.figma.com/design/Sdy6smlooBjashjhqnSGL1/projeto?node-id=2-9041). O projeto usa HTML, CSS e JavaScript sem dependências.

Abra `index.html` no navegador para ver a página. O projeto já inclui cabeçalho, primeira tela, menu mobile, indicadores, seção Sobre e programação por dia. A marca e a arte geométrica foram recriadas a partir do canvas do Figma, onde medidas e estilos de camada exigem login para inspeção.

Os números dos indicadores foram transcritos do protótipo. A foto da seção Sobre é uma ilustração provisória gerada com ImageGen, identificada na página. Ela pode ser substituída pelo arquivo original do Figma em `assets/`.

A agenda reproduz as quatro atividades de 23 de novembro visíveis no Figma e marca os dias 24 a 27 como pendentes. Use as setas do teclado para alternar os dias ou baixe a versão em texto na própria seção. O nome do campus, a URL de inscrição e os dados oficiais da programação aguardam confirmação. Palestrantes e Contato serão implementados nas próximas etapas.
