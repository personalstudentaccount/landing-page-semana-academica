# Semana Acadêmica de Tecnologia

Landing page acadêmica baseada nos frames desktop e mobile do [Figma Design](https://www.figma.com/design/Sdy6smlooBjashjhqnSGL1/projeto?node-id=2-9041). O projeto usa HTML, CSS e JavaScript sem dependências.

Abra `index.html` no navegador para ver a página. O projeto já inclui cabeçalho, primeira tela, menu mobile, indicadores e seção Sobre. A marca e a arte geométrica foram recriadas a partir do canvas do Figma, onde medidas e estilos de camada exigem login para inspeção.

Os números dos indicadores foram transcritos do protótipo. A foto da seção Sobre é uma ilustração provisória gerada com ImageGen, identificada na página. Ela pode ser substituída pelo arquivo original do Figma em `assets/`.

O nome do campus e a URL oficial de inscrição aguardam confirmação. As seções Programação, Palestrantes e Contato serão implementadas em etapas posteriores. Enquanto isso, seus links indicam o estado de cada informação.
